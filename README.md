# Mobile Ecommerce Frontend

## Introduction
The Mobile Ecommerce Frontend project is a mobile application that allows users to shop online easily and conveniently. The app provides a user-friendly interface and a smooth user experience.

## Technologies Used
- **React**: The main framework for developing application.
- **Redux**: State management for the application.
- **Axios**: Library for making API calls.
- **React Navigation**: Navigation between screens.
- **Styled-components**: Library for writing CSS in JavaScript.
- **Bootstrap**: Framework for responsive design and UI components.

## Description of System Pages
- **Home Page**: Displays featured products and product categories.
- **Product Page**: Details about the product, including images, description, and price.
- **Cart Page**: List of products added to the cart and the total order value.
- **Checkout Page**: Enter shipping information and payment method.
- **Account Page**: Manage personal information and order history.
